# 🏡 House Prices Prediction

## 📌 Project Overview
This project focuses on predicting house sale prices using Machine Learning techniques.

The goal is to predict the final price of residential homes based on various features such as quality, area, location, and other property characteristics.

Dataset: [Kaggle - House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 🔍 Project Workflow
1. Data Loading and Exploration
2. Exploratory Data Analysis (EDA)
3. Handling Missing Values
4. Feature Engineering
5. Categorical Encoding (One-Hot Encoding)
6. Model Training
7. Model Evaluation
8. Final Predictions and Kaggle Submission

## 🤖 Machine Learning Model
**Random Forest Regressor**

The model was trained using log-transformed target values to improve prediction performance.

## 📊 Results

| Metric | Score |
|---|---:|
| Validation RMSLE | 0.14756 |
| Kaggle Score | **0.14321** |
